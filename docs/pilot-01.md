## 样本与执行路径

使用用户此前提供的第一张完整参考图，画布为 1089 × 385，包含 (a) 至 (d) 四个分区。输入只有图片，没有原始生图提示词。本轮视觉理解与坐标、样式、文字清单由当前对话中的模型生成；确定性工具执行这些描述，不负责从图片自动推断结构。

实际路径：整图分析 → 带稳定 ID 的场景 JSON → SVG 校验与预览 → Figma MCP 上传 RGB 素材 → 原生文字、矩形与 SVG 路径建图 → Figma 预览 → 修正边框 → 原生导出。

本轮实际使用 Figma MCP。它承担写入和检查图层的工作，VLM API 不参与。普通网页模型的输出也可以交给同类执行工具；完全脱离 MCP、保持原生可编辑文字的本地 Figma 插件尚未实现。仅将 SVG 拖入 Figma 不能据此保证原生文字的编辑能力。

## 偏差与尚未验证的内容

- 小车图标采用手工定义的矢量轮廓近似重绘，没有找到或验证原作者的同款矢量素材。
- 字体为根据参考图推断的匹配；尚未取得原作者字体信息，字距与细节不保证一致。
- RGB 来自用户提供的低分辨率参考图，视频帧堆叠采用相同画面复用；论文正式版本宜替换为数据集原图。
- 本轮人工检查了主要布局和连线方向，没有完成逐像素差异验收或科研内容正确性审查。
- 尚未验证其余两张参考图中的密集跨区连线、公式、复杂机器人图标和全部手绘效果。
- SVG/PDF 的格式具备矢量内容，不等于已经达到指定期刊或会议在最终排版尺寸下的全部要求。
