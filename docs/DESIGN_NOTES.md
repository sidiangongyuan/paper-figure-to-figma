# Presentation references

The presentation uses a warm paper palette, dark green typography, restrained borders and generous spacing. The main story follows a researcher's next revision: inspect a real figure, change a detail, download it and continue working.

| Reference | Pattern studied | Adaptation here |
| --- | --- | --- |
| [MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search) | Concrete outcome, a short core workflow, setup separated from advanced material | One complete PlanWAM example and two concise entry paths |
| [anomalyco/opencode](https://github.com/anomalyco/opencode), [product page](https://opencode.ai/) | Early product demonstration and a clear starting action | A replay on the repository front page and an offline interactive preview |

The visual identity, interface, copy, SVG artwork and demo code were authored for this project. No reference branding or implementation has been copied. The browser demo is explicitly labeled and uses the actual reviewed Figma export.

Original example source: [PlanWAM: Planning-Shaped Future Representations for End-to-End Autonomous Driving](https://arxiv.org/abs/2610.11382), Figure1. Source attribution is visible beside the demo, in both READMEs, in the plugin and in the example directory.
