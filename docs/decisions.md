## 当前步骤

第一问已通过三张参考图明确图类型。参考图并不自动代表第一版必须支持其中每一种视觉细节。

第二问已确认：位图例外仅限输入 RGB 和输出结果图。其他区域不得通过嵌入图片绕过矢量重建要求。

Figma 编辑粒度已确认：文字直接修改内容、字体和字号；模块框独立编辑；箭头独立编辑路径与线型；图标分组并保留内部矢量路径。箭头自动跟随模块移动、图标内部零件的语义分组等进一步能力尚未确认。

用户进一步提出统一网页入口与代理入口的诉求。当前建议交付一个工具包，包含 Figma 插件、代理 Skill 与通用网页指令包，共用图纸、素材约定、绘制核心和校验规则。各组件职责与实现边界见 [统一交付方案](workflow-proposal.md)。插件与 Skill 尚未完成封装；跨入口工程切换和通用增量更新仍需验证。第一版人工上传、下载与复制已确认，后续网页自动操作尚未决定。

图标回退策略已确认：优先寻找同款素材，找不到时尝试忠实矢量重绘，困难项单独标记。该选择确定处理原则，不代表已验证所有图标都能准确重绘。

原图疑点处理已确认：先忠实还原，问题清单与还原结果一起交付，修正经用户确认后执行。

标准输入更新为图片必需、原始生图提示词可选，支持复现已有科研图。工具包提供的重建指令与原图的生图提示词是两类材料：前者由工作流提供，后者缺失时仍可开始。模糊文字、含义不明的图标与不清楚的连线按疑点规则处理。

输入范围已明确为完整参考图。先分析全局布局、分区与跨区连线，再在统一画布坐标中分区重建，合并后检查完整结果。

此前选择的局部验证属于内部开发步骤：可以先检查文字、模块、箭头和复杂图标的矢量重建与编辑质量，再验证全图布局与复杂连线。第一张参考图的 (d) 区域只是此前的测试建议，不是输入要求，也不是限定的最终交付范围。首个整图测试已使用第一张完整四分区图，无需原始生图提示词。结果与偏差见 [测试记录](pilot-01.md)；通用精度验收标准仍待明确。

本轮实际验证的是当前对话模型生成场景图纸，再通过 Figma MCP 建立原生图层的路径。仓库已加入场景执行原型，尚未完成可安装的本地插件或通用自动识图工具。MCP 可以由其他 Figma 写入方式替代，但本轮没有验证完全脱离 MCP 的原生图层导入。

首轮用户复核暴露了渐变、标签底板与压缩箭头曲率遗漏，已新增修订画板与特征检查；正文默认 Times New Roman，最小编辑字号 16，论文最终尺寸另验收。原因与验收顺序见 [视觉复核记录](visual-review.md)。当前尚需明确论文最终验收版面。

## 后续决策依赖

以下为讨论顺序草案，不是已确认需求，也不是同时要求用户回答的问题。

1. 代表性参考图与第一版覆盖范围。
2. 编辑能力：基础编辑粒度已确认；连线自动跟随、公式等进一步要求待讨论。
3. “1:1”如何验收：布局、文字、颜色、形状、局部细节分别允许多少偏差。
4. 在已确认的位图边界下，复杂图标、插画、纹理等如何做矢量重建。
5. 原图疑点处理原则已确认；无法辨认的文字等具体处理细节待讨论。
6. 标准输入已确认：图片必需、原始生图提示词可选；输入 RGB 和输出结果图的原始素材如何提供与映射仍待讨论。
7. 自动化程度与人工校正步骤。
8. 模型/API、Figma 接入方式、运行环境与预算。
9. 输出格式、字体、论文尺寸与质量检查。
10. 第一张完整参考图已完成首次测试；其余图类型、质量阈值与第一版完整范围仍待确定。

## 约束

- 外观相似、真正矢量化、便于编辑、科学表达正确，需要分别检查。
- SVG 文件后缀不能单独证明内容全部是矢量；也不能证明文字仍可作为文字编辑。
- 当前没有承诺任意图片都可自动、无损、全矢量重建。
- 每项决策标明来源；推荐方案在用户确认前保留为候选。
