# Prompt Builder

The [Prompt Builder](https://sidiangongyuan.github.io/paper-figure-to-figma/) composes the request you send to the assistant together with the reference image.

1. Choose a template.
2. Adjust fonts, color scheme or paper figure width as needed, and describe any specific changes.
3. Copy the prompt and send it with the complete reference image to an assistant that has the skill installed.

The default prompt is a single line; each option you change adds one requirement.

The page also works offline: open `web/index.html` from a downloaded copy of the repository.

See [Installation and Usage](CODEX_QUICKSTART.md) to set up the skill.
