# 首轮复核暴露的问题与修订规则

日期：2026-10-19。此记录区分新增排版偏好与原本应该还原却被遗漏的细节。

## 原因核查

| 项目 | 核查证据 | 结论 |
| --- | --- | --- |
| 字体与字号 | 首轮使用 Arial，部分文本为 12–13；当时未定义统一论文作图字体 | 用户新增排版规范，之后按此规范执行，不再照抄原图字体 |
| Predicted Future Latent 渐变 | 原图 token 中心像素随纵向连续变亮；首轮场景只保存了两个纯色色值，矩形导入器只生成 SOLID 填充 | 识图描述遗漏，同时缺少矩形渐变描述；Figma/SVG 本身能够表达渐变 |
| DINO / JEPA / BEV 底板 | 原图包含浅色半透明矩形；首轮场景为 token 网格后直接叠文字，未创建底板 | 底板未进入元素清单，执行器没有丢失已有图层 |
| 压缩箭头曲率 | 原图局部放大后曲率清楚；首轮脚本用两个端点画了一条直线 | 路径类型被错误简化；此前轨迹曲线已经证明贝塞尔路径可用 |

首轮通过的检查主要覆盖文本对象、位图边界、文件结构和整图主要布局。它们不能证明细节完整。之前进行了渲染查看，但局部逐项比对不足，明显的遗漏仍未被发现。

## 已确认排版默认值

- 正文默认 Times New Roman，用户明确指定字体时覆盖默认值。
- 标题和大字可用 Times New Roman 或 Comic；当前修订图保留两处分支标题为 Comic Sans MS。
- 编辑画布默认字号至少 16，允许缩放或调整画布。场景校验默认阈值为 16；特殊图的例外通过显式排版策略记录。
- 用户选择 A：16 的要求针对编辑画布；放入论文后的物理字号、缩放比例和可读性另外验收。单纯扩大编辑画布不能证明论文最终字号变大。

## 修订版结果

原始测试画板保留。新增修订画板使用 41 个 Times New Roman 文本、2 个 Comic Sans MS 标题，最小编辑字号为 16；画布约为 1452 × 513.33，整体放大 4/3。

已补回 8 个纵向渐变 token、3 个半透明白色标签底板，并将压缩箭头改为三次贝塞尔曲线。位图仍为 21 个视频帧图层，复用两份 RGB 素材。渐变色标和底板透明度根据低分辨率参考图估计，并非已取得原始矢量参数。

修订图的 Figma 预览已逐项查看；导出的 SVG 保留 43 个文本，最小 `font-size` 为 16，两份内嵌图片。SVG 导出会对画布边界取整，导出高度为 514。当前校验共有 8 项测试通过。

## 后续必须执行的检查顺序

1. 全图理解后，内部裁出分区和高密度细节，结合整图查看。用户仍只需提供整图。
2. 在建图前列出细节清单：文字与底板、遮挡顺序、透明度、渐变方向与色标、路径类型与控制点、圆角、线型和端点。不因颜色浅或接近白色而跳过对象。
3. 单独核对细节清单是否忠实于原图。清单自身可能漏项，不能直接把它当作完整真值。
4. 将已识别的关键特征列为 `visualFeatures`，绑定稳定元素 ID。已要求的渐变、底板、曲线缺失或被简化时，校验失败。
5. 生成同尺寸整图与局部对照。先看原图和渲染结果列差异，再回到图层和场景定位原因；检查底板是否位于文字下方、渐变方向是否正确、曲率是否接近。
6. 分开报告可编辑性、视觉相似度、论文最终尺寸可读性与科研含义。结构计数或“SVG 后缀”不得替代视觉验收。

`visualFeatures` 校验只检查清单中已知的特征，不会自动发现未知漏项。本轮也不证明任意科研图均能自动无损重建。

## 实现变化

矩形填充现在支持带方向和色标的线性渐变；透明度在 SVG 与 Figma 中保留。SVG 中的曲线路径和 viewBox 缩放也有回归检查。新增的特征清单检查会拦截缺失底板、错误层序、将渐变改成纯色以及将曲线改成直线的情况。
