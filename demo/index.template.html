Quick Start

网页模型 + Figma 插件

准备 Figma 桌面版和支持看图的网页模型账号。

  1. 1
    安装插件

    解压 ZIP。在 Figma 中打开 Plugins → Development → Import plugin from manifest…，选择 figma-plugin/manifest.json。

  2. 2
    运行样例

    运行 Paper Figure to Figma (local)，点击「加载 PlanWAM 示例 → 生成到 Figma」。

  3. 3
    重建参考图

    在插件中选图、复制指令，发给网页模型。导入返回的 .json 文件，对照修改后导出。
