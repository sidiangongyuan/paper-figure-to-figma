网页会员可用 · 无需模型 API

把科研参考图带进 Figma

模型读图并给出绘制文件，这里生成可编辑图层。先试内置示例，再导入自己的完整参考图。

1把参考图和指令发给模型

无需原来的生图提示词。先用清晰的 PNG 或 JPG。

在你使用的网页模型中上传同一张图，再发送下面的固定指令。

查看指令 / 复制失败时手动复制

2导入模型的绘制文件

同 projectId 再次导入会更新该项目画板。更新会按文件重建对应图层；手动调整后请先复制画板备份。

尚未导入。可以先加载入门示例，然后点击「在 Figma 生成 / 更新」。

3对照、修改与交付

下载预览，把它与原图、项目文件一起发给模型复核。复制复核指令，取得完整修订文件后回到第 2 步。

全局和局部视觉对照通过后，再检查论文最终尺寸的可读性。

输出保留原生文字和独立矢量。只有输入 RGB / 输出结果保留图片。插件不连接模型，不会自动实现任意图片 1:1 重建。
